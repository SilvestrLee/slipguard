# Success Metrics

## MVP Product Signals
- First analysis completion.
- Weakest-leg explanation opened.
- Report saved or revisited.
- Journal decision recorded.
- User returns to analyze another slip.
- User reports that the analysis is understandable.

## Guardrails
- Analysis failure rate.
- Misleading claim incidents.
- Authorization failures.
- Unexplained score complaints.
- Abandonment caused by confusing input.

## Do Not Optimize For
- Number of bets.
- Bet volume.
- Gambling frequency.
- False urgency engagement.
