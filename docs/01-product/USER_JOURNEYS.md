# User Journeys

## First Analysis
1. Understand SlipGuard evaluates risk, not outcomes.
2. Register and enter the workspace.
3. Start an analysis.
4. Enter slip legs.
5. Fix validation errors.
6. Receive a report.
7. Review the weakest leg.
8. Save or revise the slip.

## Return and Learn
1. Review recent analyses.
2. Open history.
3. Record placed, revised, or skipped.
4. Add a reflection.
5. Apply the learning to another analysis.

## Operations Review
Authorized staff inspects users, slips, analyses, engine versions, rule outputs, incidents, and feature flags.
