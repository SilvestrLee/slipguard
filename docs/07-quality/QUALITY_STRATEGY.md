# Quality Strategy

## Objectives
Correct deterministic results, strong ownership authorization, understandable customer output, a stable primary journey, traceable engine versions, and safe failure behaviour.

## Unit Tests
Odds normalization, combined odds, rule calculations, risk bands, weakest-leg selection, and engine determinism.

## Feature Tests
Authentication, slip creation, authorization, analysis submission, report access, history, journal, and Filament access.

## Browser Tests
Add only for critical journeys after screens stabilize.

## Release Rule
A milestone is incomplete until acceptance tests pass and the outcome can be demonstrated.
