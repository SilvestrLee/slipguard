# Security Baseline

- Authorize every customer-owned resource.
- Never trust ownership IDs from the client.
- Validate and normalize odds.
- Escape customer-provided text.
- Rate-limit analysis submission.
- Protect Filament routes and staff access.
- Audit staff changes to rules and flags.
- Keep provider credentials private.
- Do not expose raw exceptions.
- Avoid sensitive user data in logs.
- Store only data required by the product.
