# SlipGuard Operating System

SGOS is the durable repository context for SlipGuard.

It explains what SlipGuard is, what is being built, why major decisions were made, and how implementation should proceed.

Do not populate every folder in advance. Use just-in-time documentation.

This document, and everything under `docs/00-governance/` through `docs/09-compliance/` and `docs/adr/`, forms SGOS — see `docs/00-governance/SGOS_VERSION.md` for the current version. If another document conflicts with SGOS, SGOS takes precedence. `docs/_legacy-bootstrap/` is explicitly excluded from this authority; it is superseded history, not a second source of truth.
