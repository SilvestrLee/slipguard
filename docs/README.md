# SlipGuard Operating System

SGOS is the durable repository context for SlipGuard.

It explains what SlipGuard is, what is being built, why major decisions were made, and how implementation should proceed.

Do not populate every folder in advance. Use just-in-time documentation.

This document, and everything under `docs/00-governance/` through `docs/09-compliance/`, `docs/adr/`, `docs/offices/` (the standing constitution for each governance office — Product, Architecture, Engineering, UX Studio, Data Science Lab, Compliance, Parser), and `docs/engineering/` (engineering validation and production-certification reports), forms SGOS — see `docs/00-governance/SGOS_VERSION.md` for the current version. If another document conflicts with SGOS, SGOS takes precedence. `docs/_legacy-bootstrap/` is explicitly excluded from this authority; it is superseded history, not a second source of truth.

For current state rather than durable structure, check `TASKS.md` (active milestone and task list), `docs/00-governance/DECISION_LOG.md` (dated record of every governance and product decision, with reasoning), and `CHANGELOG.md` (what has shipped) — none of these are part of SGOS itself, but they are where "what's happening now" actually lives.
