# UX Rules

## Goal
Make betting-risk analysis understandable to a non-technical accumulator bettor.

## Language
Use short direct sentences, explain unfamiliar terms, never shame the user, never imply certainty, and always distinguish risk analysis from outcome prediction.

## Every Screen Must Answer
1. What is happening?
2. Why does it matter?
3. What should I do next?

## Visual Direction
Use minimal layouts, strong hierarchy, restrained colour, readable typography, clear status labels, calm feedback, and accessible contrast.

Avoid casino aesthetics, neon palettes, flashing elements, confetti, fake urgency, countdown pressure, overloaded dashboards, and charts without decision value.

## Risk Report Hierarchy
1. Plain-language headline.
2. Overall risk band.
3. Weakest leg.
4. Main reasons.
5. Per-leg detail.
6. Methodology and disclaimer.
7. Save, revise, or journal action.

## Accessibility
Keyboard controls, visible focus, proper labels, semantic headings, no colour-only meaning, responsive layout, and plain-language validation.
